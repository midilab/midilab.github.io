OpenDSP

A headless, DSP OS platform for professional, low-latency audio and video processing on a budget.

Generic IntelLive Generic IntelRaspberry PI 2/3

Emulate classic synthesizers, effect boxes, dynamics processors, video processors, and more. No mouse, no keyboard, no monitor!

Inspired on Muse Receptor, but completely free and affordable to build! OpenDSP allows you to turn your your old PC or Raspberry Pi or into a standalone machine for audio, video, and general digital signal processing, offering low latencies and excellent performance on a budget.

No need for a monitor, keyboard, or mouse. By utilizing MIDI and OSC protocols, you can control your OpenDSP with a variety of products on the market, from MIDI controllers to OSC programs running on a tablet or smartphone.

OpenDSP enables you to emulate classic music machines such as the Yamaha DX7, Moog, Nord Lead 2x, Access Virus A/B/C/TI, Waldorf microQ/microWAVE, Fender Cabinets, Roland Space Echo 201, Spring Reverbs, and more.

Program real-time interactive images, video, and audio using Processing and Puredata in a fully customizable and automated environment, designed for performers, art installations, or studio sessions.

Features​

Read only filesystem

Wich means you can just turn it off without risking data inconsistences

LIgthwiegh OS

No bloat software or fancy GUIs, the OS is shipped only with ligthweith apps and barebone to DSP and video only, letting the cpu works for you setup instead of background and bloated non used software.

MIDI and OSC Controllable

Controls apps and project loading, save using only MIDI or OSC protocols.

Network Share

All user data including samplers, DJ set music files, and system configurations can be accessed from Linux, Mac, or Windows without requiring any prior configuration. Simply search for the network share named “opendsp.”

Virtual Screen

Depending on the opendsp app ecosystem, certain programs may require X11 support. In such cases, you have the option to interact with a web browser interface. Access it through this address: http://opendsp/. Alternatively, for a more stable connection, you can use direct VNC access at “opendsp:5900.”

DSP Suite

loopers: giada, luppp djing: mixxx, wxax daw/sequencer: lmms, hydrogen, qtractor, non-daw, non-mixer, non-sequencer trackers: sunvox, milkytrack, klystrac modular synthesis: carla, carla-rack, ingen Processing plugins: 410+ audio plugins, from effects to classic synthesizer emulations

Video Suite

video: lebiniou, omxplayer, vlc

Access Point ready for remote access

OpenDSP features built-in plug-and-play support for WiFi dongles. It automatically creates an access point named “OpenDSP,” allowing you to interface with your opendsp via WiFi using your mobile phone or tablet. The default password is “opendspd.”

Dedicated Video Output

Please note that the main video output, typically accessed through HDMI or DVI ports, is dedicated to video projection. Therefore, it is recommended not to use this display for app management purposes. Instead, utilize the Virtual Display.

Highly Hackable

Easily create your own embbeded headless DSP engine with a few lines of configuration, combine any app in opendsp ecosystem for a final product. A real-time kernel and a sub-set of opensource applications, plugins and tools makes OpenDSP vastly hackable for different kinda of DSP tasks.

Applications​

OpenDSP applications are called "mods" wich are configuration setups that automatically launch and connect multiple applications to function as a single cohesive system. These powerful configurations offer several key benefits:

Core Features​

  • Headless Operation: Control your audio/video processing entirely via MIDI or OSC protocols without requiring a mouse or monitor.
  • Project Management: Load different mods or projects within mods, and save your work for later use.
  • Flexible Display Options: Run with no display for maximum CPU efficiency or use a virtual display accessible from mobile devices, tablets, or laptops when GUI control is needed, offloading you main video output wich is ideal for VJs who need to dedicate their main video output for projections.

Simple Configuration​

Creating your own mods requires just a few lines of configuration to establish interconnected applications that can be fully automated and controlled via MIDI or OSC protocols.
