Aciduino

DIY Roland TB-303 & TR-808 Sequencer Clone with added features. A performance sequencer, composition tool, and MIDI controller all in one compact package.

Download Latest ReleaseBrowse Aciduino Repository

A DIY multitrack sequencer, compose tool, and MIDI controller, designed using readily available, inexpensive parts. It supports different microcontrollers and can be easily assembled on a protoboard or ordered as a PCB.

From barebone to full hands-on control! You can hook up to 16 pots, 24 buttons/LEDs, MIDI interfaces, and CV/Gate to extend your barebone Aciduino.

Barebone

Easy assembly, maximum fun! Get your sequencer up and running in under an hour with this minimalist barebone build of a fully functional step sequencer and MIDI controller.

Button/LED Extension

Expand the control capabilities of your sequencer by adding up to 24 buttons/LEDs, enabling a full set of real-time editing functions, similar to those found on a TR-808.

Pot Extension

Expand your MIDI controller interface with up to 16 potentiometers!

3D Printed Case

Keep your Aciduino safe on the road! All the 3D print files and schematics are available!

Features​

Beyond the classic and well-known features of the TB-303 and TR-808 sequencers, several additional features are included for both studio and live performance use.

Tight and Solid Clock

Using a hardware timer to achieve real-time, professional-grade timing for both internal and external synchronization. Send or receive clock signals, keeping all your gear tightly synced.

Compose Tool

Generate acid pattern sequences at the push of a button and by twisting some parameters. Harmonizer for melodic tracks and Euclidean algorithm for drum tracks.

Pattern Grid Scene

Inspired by Ableton Live's Scene mode, the sequencer allows you to freely recall any track pattern or entire pattern scene using a navigable grid system, just like Ableton Live's Scene mode.

Mute Grid Scene

Create up to 4 mute states within a pattern scene. The first sequencer in history to include such a feature. Craft intros, build-ups, and drops to maximize the use of a single pattern scene.

Midi Controller

The most affordable MIDI controller you can build, controlling up to 16 parameters per track on your external synthesizers (bass/drums).

TR-909 Swing

Add TR-909 swing to your drums and basses for shaking tracks. Aciduino uses the same algorithm that gives the TR-909 its groove signature!

Highly Configurable

You can choose how many TB-303 and TR-808 tracks to use, up to 16 tracks and 512 steps. Go way beyond what the original Roland machines have to offer.

Easily Hackable

Don't be stuck with the original barebone layout. Easily create your own hardware layout and user interface. Adding and removing features is a breeze with Aciduino's modular architecture.

Live Record

Real-time and step recording modes for MIDI keyboard input.

Embedded Pattern Memory

Store your work using the microcontroller's EEPROM memory.

Assembly​

The assembly process is designed to be straightforward, taking approximately one hour when using a protoboard. It uses readily available and inexpensive parts.

Aciduino in action​

Aciduino Live Performance

Performing Puhture's "Acid Track" with 2x TB-303 and 1x TR-808 tracks, using the same TB-303 programming notation as the original track. This performance relies solely on the Mute Grid system, moving back and forth between the intro, 2x build-ups, and a drop mute state.

Aciduino Live Composing

Live composing and performing a track from scratch using Aciduino's composition tools, utilizing the harmonizer for melodic lines with the Ionian mode and a Euclidean rhythm generator for drum and percussive tracks.

Aciduino V1

Aciduino V1 live performance with 2x Roland Cloud TB-303 and 2x Dave Smith Tetra tracks, while sending a sync clock signal to a Roland Cloud TR-808.

Aciduino V1 Mod

SEQ32: A fantastic mod of Aciduino V1, featuring 3 tracks, 4 extension pots per track, and a button/LED array extension for step note control, built and performed by Conrad Vassallo.
