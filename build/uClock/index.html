µClock

A tight BPM clock generator for Arduino and PlatformIO using hardware timer interruption. AVR, Teensy, STM32xx, ESP32 and RP2040 support

Download Source Code

The uClock BPM Generator library enables precise and reliable BPM clock tick calls using microcontroller timer hardware interruptions. Designed for multi-architecture use, it provides a robust solution for real-time processing in music, audio/video productions, performances, and tech art installations.

Features​

...

Multi-Architecture Support

Supports ARM boards (Teensy, STM32XX, ESP32, Raspberry Pico, Seedstudio XIAO M0, RP2040) and AVR boards (ATmega168/328, ATmega16u4/32u4, ATmega2560). For non-supported boards there is a software emulation mode.

Real-Time Processing

Leverages hardware interrupts to schedule and manage timing with safe shared resource access through its API. Enables professional-grade sequencers, sync boxes, and precise BPM clocks for external devices.

Cross-platform

Arduino and PlatformIO support to achieve maximun cross-platform score.

External Sync Mode

Generates internal clock based on an external clock source, facilitating MIDI synchronization and protocol adherence.

Applications​

Real world devices using the uClock library:

Aciduino V2

The project features a versatile step sequencer clone of Roland's TB303/TR808, offering up to 16 tracks. It includes a comprehensive automation grid system for step, pattern, and mute control. The sequencer functions as a MIDI controller and incorporates an OLED display for visual feedback. Furthermore, the design is modular and allows for easy expansion with additional potentiometers, buttons, MIDI, or CV/Gate interfaces.

A full featured groovebox using uClock library, created by James Gray

MIDI Looper/Sequencer

MIDI/DIN Clockbox

A MIDI and DIN clockbox using uClock library, created by ymnkmusic.

How to use​

Installation​

  1. PlatformIO
    • Clone the repository into your project directory.
    • Add #include "uClock.h" and include the library in your PlatformIO build system.
  2. Arduino Compatibility
    • Ensure your board is supported (see README for list).

Initialization​

// Default initialization
uClock.init();

// Custom configuration
uClock.setPPQN(uClock.PPQN_384);
uClock.setOnSync24(onSync24Callback);
uClock.start();

Usage​

  • Timing Events: Use callbacks (onPPQN, onStep) for precise BPM control.
  • External Sync: Enable via setMode(EXTERNAL_CLOCK) and process external signals in loop().
  • Stop/Start: Control with stop() and start() methods.

Examples​

  • Visit the examples directory for detailed implementations, including MIDI sync boxes and step sequencers.
