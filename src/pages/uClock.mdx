The uClock BPM Generator library enables precise and reliable BPM clock tick calls using microcontroller timer hardware interruptions. Designed for multi-architecture use, it provides a robust solution for real-time processing in music, audio/video productions, performances, and tech art installations.

## How to use

### Installation

1. **PlatformIO**
   * Clone the repository into your project directory.
   * Add `#include "uClock.h"` and include the library in your PlatformIO build system.
2. **Arduino Compatibility**
   * Ensure your board is supported (see README for list).

### Initialization

```cpp
// Default initialization
uClock.init();

// Custom configuration
uClock.setPPQN(uClock.PPQN_384);
uClock.setOnSync24(onSync24Callback);
uClock.start();
```

### Usage

* **Timing Events**: Use callbacks (`onPPQN`, `onStep`) for precise BPM control.
* **External Sync**: Enable via `setMode(EXTERNAL_CLOCK)` and process external signals in `loop()`.
* **Stop/Start**: Control with `stop()` and `start()` methods.

### Examples

* Visit the **examples** directory for detailed implementations, including MIDI sync boxes and step sequencers.
