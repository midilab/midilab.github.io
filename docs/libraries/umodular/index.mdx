µMODULAR is an open-source toolkit for building custom MIDI controllers and instruments. It provides a **KiCad schematic library** (`lib/`) of reusable hardware building blocks and a set of **tested PCB modules** (`v1/`) that you can build, combine, and expand.

- **License:** CC-BY-SA 4.0
- **Repository:** [github.com/midilab/uMODULAR](https://github.com/midilab/uMODULAR)
- **Website:** [midilab.co/umodular](https://midilab.co/umodular)

---

## `lib/` — KiCad Schematic Library

The `lib/` directory contains KiCad schematic modules (`.sch`) and PDF reference sheets that serve as reusable building blocks. Open the combined project `umodular_libs.kicad_pcb` in KiCad to mix and match these modules into your own custom PCB designs.

| Module | Description | Files |
|--------|-------------|-------|
| **POT8** | 8× potentiometer input (multiplexed) | `pot8.sch`, `pot8.pdf` |
| **POT16** | 16× potentiometer input (multiplexed) | `pot16.sch`, `pot16.pdf` |
| **PUSH8** | 8× button + LED matrix | `push8.sch`, `push8.pdf` |
| **PUSH16** | 16× button + LED matrix | `push16.sch`, `push16.pdf` |
| **LED8** | 8× LED output | `led8.sch`, `led8.pdf` |
| **LED16** | 16× LED output | `led16.sch`, `led16.pdf` |
| **MIDI** | MIDI I/O (5V) | `midi.sch` |
| **midi-io-5v** | MIDI interface reference | `midi-io-5v.pdf` |

An overview schematic (`overview.pdf`) shows how the modules interconnect.

To use: clone the repo, open `lib/umodular_libs.kicad_pcb` in KiCad, copy the desired schematic sheets into your project, and wire them to your microcontroller.

These are ready-to-build PCBs designed using `lib/` schematics. Each module connects to an Arduino-based shield via ribbon cable headers.

## Firmware Libraries

µMODULAR hardware pairs with two firmware libraries built for Arduino (PlatformIO):

- [**µClock**](/docs/libraries/uclock/intro) — BPM-accurate clock generator using hardware interrupts
- [**µCtrl**](/docs/libraries/uctrl/intro) — Driver layer and UI framework for all µMODULAR modules

Both support AVR (ATmega168/328/16u4/32u4/2560) and ARM (ESP32, SAMD21, Teensy) architectures.

## Applications

Real-world projects built with µMODULAR:

- **Aciduino V2** — 16-track Roland-inspired step sequencer
- **Atari 2600 MIDI Station** — Live sequencer and MIDI controller
- **Oberheim Matrix Controller** — Commercial controller with arpeggiator (by Alpes Machines)
- Various community projects: gesture sequencers, drum synths, looper pedals

## Getting Started

1. Clone the repository: `git clone https://github.com/midilab/uMODULAR.git`
2. Browse `lib/` for schematics or `v1/` for ready-to-build PCBs
3. Order PCBs from your favorite fab house using the Gerber files
4. Pair with [µClock](/docs/libraries/uclock/intro) and [µCtrl](/docs/libraries/uctrl/intro) firmware
5. Join the [Discord community](https://discord.gg/DCb3dy5A) for help and project sharing
